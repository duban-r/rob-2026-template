# Робота 5. Від «якщо» до регулятора

## Умова

Зробити одну задачу — рух за лінією — **трьома способами**
й порівняти їх числами.

**Світ:** Worlds → Select World → **Line Following Challenges**, траса
**Simple Curves**. Це не коло, а смуга з поворотами: робот стартує на
лінії, і міряємо **час до кінця траси**.

### Каркас — спільний для всіх кроків

```python
from ev3dev2.motor import MoveTank, OUTPUT_A, OUTPUT_B, SpeedPercent
from ev3dev2.sensor import INPUT_1, INPUT_4
from ev3dev2.sensor.lego import ColorSensor
from ev3dev2.sensor.virtual import GPSSensor
import time

tank = MoveTank(OUTPUT_A, OUTPUT_B)
color = ColorSensor(INPUT_1)          # ⚠️ у Gears порт обов'язковий
gps = GPSSensor(INPUT_4)              # лише щоб зупинити секундомір на фініші
time.sleep(0.5)

PORIH = 50                            # з роботи 4: біле 100, чорне 1


def obmezhyty(v):
    """SpeedPercent поза ±100 у Gears падає з ValueError."""
    return max(-100, min(100, v))


pochatok = time.time()
while time.time() - pochatok < 120 and gps.y < 85:
    v = color.reflected_light_intensity
    # ↓↓↓ сюди — код кроку 1, 2 або 3 ↓↓↓

tank.off()
print("час до кінця траси: %.1f с" % (time.time() - pochatok))
```

⚠️ GPS тут — лише секундомір. У самому керуванні його **не використовувати**.

### Крок 1. Релейний варіант

Вставити в цикл:

```python
    if v < PORIH:
        tank.on(SpeedPercent(10), SpeedPercent(0))
    else:
        tank.on(SpeedPercent(0), SpeedPercent(10))
```

Запустити **три рази**. Записати час кожного прогону.

⚠️ Робот їхатиме, виляючи, і повільно. Це нормально й це не помилка —
команда має лише два значення, тому помилка 1 і помилка 40
обробляються однаково.

### Крок 2. Пропорційний регулятор

Замінити код у циклі на:

```python
    e = PORIH - v
    korekciya = Kp * e
    tank.on(SpeedPercent(obmezhyty(BAZA - korekciya)),
            SpeedPercent(obmezhyty(BAZA + korekciya)))
```

А **перед циклом** додати:

```python
BAZA = 20
Kp = 0.5
```

Підібрати `Kp` за порядком: підіймати, доки робот не почне
**розгойдуватись**, потім узяти приблизно половину. Кожне спробуване
значення — рядок у таблиці. Обраний `Kp` — **три прогони**.

### Крок 3. Знайти межу

Значення `Kp`, за якого робот починає **розгойдуватись** —
перелітати через лінію туди-сюди й злітати з траси. Записати його.

## Якщо щось пішло не так

| Що бачите | Причина | Що зробити |
|---|---|---|
| `TypeError: No color sensor connected to null` | датчик без порту | `ColorSensor(INPUT_1)` |
| `ValueError: Value must be between -100 and 100` | швидкість вийшла за 100 % | загорнути в `obmezhyty(...)` |
| робот одразу з'їжджає з лінії й їде геть | `Kp` замалий або знак навпаки | перевірити: `e = PORIH - v`, ліве `BAZA - korekciya` |
| робот крутиться на місці біля старту | `Kp` завеликий | зменшити вдвічі |
| цикл не закінчується | робот загубив лінію й не дійде до фінішу | зупинити ■, записати «не доїхав» — це теж результат |
| `gps.y` не росте | інший світ або інша траса | Line Following Challenges → Simple Curves |

## ⭐ Головне сьогодні

**«Зробити сильніше» не означає «зробити краще».** Завеликий `Kp`
псує все — робот починає розгойдуватись і губить лінію.

Це один із небагатьох випадків, коли інженерне правило видно
буквально очима за десять секунд.

⚠️ І не викидайте релейний варіант як «неправильний». Релейне
керування — робочий прийом там, де виконавчий орган і так має
два стани: клапан, реле, нагрівач.

## Три рівні

**Ядро (всі).** Обидва варіанти працюють, по три прогони, таблиця
заповнена.

**Трек Д.** Критерій інший: **рух має виглядати впевненим, а не
смиканим.** Зняти коротке відео трьох варіантів і описати словами,
чим вони відрізняються для стороннього спостерігача. Яке значення
`Kp` виглядає найспокійніше — і чи збігається воно з найшвидшим?

**Трек П.** Додати **D-складову** — у циклі замість кроку 2:

```python
    e = PORIH - v
    d = e - e_pop
    korekciya = Kp * e + Kd * d
    e_pop = e
    tank.on(SpeedPercent(obmezhyty(BAZA - korekciya)),
            SpeedPercent(obmezhyty(BAZA + korekciya)))
```

(перед циклом: `Kd = 1.0` і `e_pop = 0`). Таблиця Kp × Kd щонайменше
3 × 3: час до кінця траси й чи розгойдується. Чесна відповідь «Д тут
нічого не дала» — теж відповідь, якщо вона спирається на числа.

⚠️ **I-складову не беремо.** Вона потрібна там, де є стале зміщення,
і легко псує все, якщо не обмежити накопичення. Знайте, що вона є,
і йдіть далі.
